# Skills Library

This directory contains all skills (agent-readable SOPs) for BoltSite Pro.

## How Skills Work

Each skill is a markdown file that describes:
- What the skill does (goal)
- What inputs it needs
- What outputs it produces
- Step-by-step procedure
- What tools it can use

When an agent is given a skill, it reads the procedure and executes
each step, using the specified tools. The human (you) reviews the
output and approves or requests changes.

## Principle: If you do it twice, it becomes a skill.
